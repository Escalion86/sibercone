# Уведомления администраторов

Система отправляет Web Push и сообщения Telegram при новом заказе, регистрации пользователя и активации кода курса. Устройства, Telegram-чаты и события настраиваются на странице `/admin/notifications`.

## Переменные окружения

Добавьте в серверный `.env`:

```dotenv
VAPID_PUBLIC_KEY=
VAPID_PRIVATE_KEY=
VAPID_SUBJECT=mailto:info@sibercone.ru
TELEGRAM_BOT_TOKEN=
TELEGRAM_BOT_USERNAME=
TELEGRAM_WEBHOOK_SECRET=
# Исходящий прокси для Telegram Bot API на VPS
TELEGRAM_PROXY_URL=http://127.0.0.1:1081
NEXTAUTH_SITE=https://sibercone.ru
```

`TELEGRAM_CHAT_IDS` можно оставить для прежних получателей через запятую. Получатели из этой переменной объединяются с чатами, подключёнными через админку, без дублей.

`TELEGRAM_PROXY_URL` применяется только к исходящим запросам на `api.telegram.org`. Если переменная не задана, запросы выполняются напрямую. На VPS прямой доступ к Telegram заблокирован, поэтому укажите локальный xray-прокси `http://127.0.0.1:1081`.

Если VAPID-переменные отсутствуют, Web Push отключается, но Telegram и остальные запросы продолжают работать. Без MongoDB API настроек и подписок отвечает контролируемой ошибкой 5xx, не завершая процесс приложения.

## Настройка Web Push

Сгенерируйте пару ключей один раз:

```bash
npx web-push generate-vapid-keys
```

Сохраните ключи в `VAPID_PUBLIC_KEY` и `VAPID_PRIVATE_KEY`, задайте контакт в `VAPID_SUBJECT`, затем перезапустите приложение. В админке откройте «Уведомления» и нажмите «Включить уведомления в этом браузере».

## Настройка Telegram webhook

Создайте непредсказуемый `TELEGRAM_WEBHOOK_SECRET` и укажите публичный HTTPS-адрес в `NEXTAUTH_SITE`. После деплоя один раз установите webhook непосредственно на VPS:

```bash
node scripts/telegram-setup.mjs
```

Команда использует переменные окружения процесса, включая `TELEGRAM_PROXY_URL`. Если они хранятся только в `.env` и не экспортированы окружением, запустите `node --env-file=.env scripts/telegram-setup.mjs`.

Проверить состояние или удалить webhook:

```bash
node --env-file=.env scripts/telegram-setup.mjs --info
node --env-file=.env scripts/telegram-setup.mjs --delete
```

После установки webhook нажмите «Подключить Telegram» в админке, откройте ссылку и нажмите Start. Одноразовый код действует 15 минут. Команды бота: `/status` показывает состояние, `/stop` отключает чат.

## Проверка

1. Откройте `/admin/notifications` и включите браузер.
2. Убедитесь, что устройство появилось в списке.
3. Подключите Telegram-чат и обновите страницу.
4. Нажмите «Отправить тестовое» и проверьте сводку доставки.
5. Создайте тестовый заказ или пользователя и проверьте включённые каналы.

Service worker доступен по `/sw.js`. Все API под `/api/admin/...` требуют действительную cookie администратора.

## Ограничения Web Push

- iPhone и Safari поддерживают Web Push только начиная с iOS 16.4 и только для сайта, добавленного на экран «Домой».
- Push не работает в приватном окне браузера.
- Подписка хранится в браузере. После очистки данных сайта необходимо включить уведомления заново.
- Пользователь может запретить уведомления на уровне браузера или операционной системы; тогда разрешение нужно вернуть в их настройках.
